# Food Ordering System (Java)

A simple command-line-based food ordering system with user authentication, hotel selection, and cart functionality.

## How to Run the Project

1. **Download the Project**:
   - Click on the `Code` button (green) in the GitHub repository.
   - Select `Download ZIP` and extract the files to a folder on your computer.

2. **Prerequisites**:
   - Ensure you have [Java JDK](https://www.oracle.com/java/technologies/javase-downloads.html) installed.
   - Open **Command Prompt** (Windows) or **Terminal** (Mac/Linux).

3. **Run the Program**:
   - Navigate to the downloaded folder:
     ```bash
     cd path/to/FoodOrderingSystem
     ```
   - Compile and run the main file:
     ```bash
     javac FoodOrderingSystem.java
     java FoodOrderingSystem
     ```
     
## Features
- User **Signup/Login** with validation.
- Search food by **hotel** or **food item**.
- Add items to cart and place orders.

## Note
- All files **must be in the same folder** for the program to work.
